# Subtitle Translation – Tangled: Rapunzel & Flynn

## Project Overview

This project contains a Turkish subtitle translation of a selected scene from *Tangled*, featuring Rapunzel and Flynn Rider.

The translation was created by listening directly to the original English dialogue and producing the Turkish subtitles independently. No existing English subtitle file was used as the source text.

## Languages

- **Source:** English
- **Target:** Turkish

## Translation Process

The dialogue was translated directly from the original English audio.

The process involved:

- Listening to the original dialogue
- Understanding the context and intended meaning
- Reconstructing the dialogue from audio
- Translating the dialogue into natural Turkish
- Adapting expressions to fit conversational Turkish
- Maintaining subtitle timing and `.srt` formatting

## Translation Approach

The main focus was on producing Turkish subtitles that sound natural while preserving the meaning, tone, and context of the original dialogue.

Particular attention was given to:

- Colloquial expressions
- Character interactions
- Context-dependent meanings
- Natural Turkish sentence structure
- Dialogue flow and readability

For example, expressions were sometimes adapted rather than translated literally when a more natural Turkish equivalent better represented the intended meaning.

## Skills Demonstrated

- English listening comprehension
- English → Turkish translation
- Audiovisual translation
- Subtitle translation
- Cultural and contextual adaptation
- Turkish localization
- `.srt` subtitle formatting
